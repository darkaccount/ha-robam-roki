# ROBAM / ROKI 老板电器 Home Assistant 集成

[![Validate & Test](https://github.com/darkaccount/ha-robam-roki/actions/workflows/validate.yml/badge.svg)](https://github.com/darkaccount/ha-robam-roki/actions/workflows/validate.yml)

将老板电器（ROBAM / ROKI）App 账号下的抽油烟机等智能厨电接入 Home Assistant。
本项目为开源社区**非官方**集成，支持云端双通道（REST / MQTT）与实时推送，开箱即用。

> 当前状态：油烟机已真机（R8229）验证可用——登录、设备发现、属性读取、开关、档位调节、灯光控制、延时倒计时。灶具、洗碗机、净水器、蒸箱/蒸烤一体机、烤箱、微波炉、消毒柜支持**只读遥测**（暂无控制功能），其余品类以原始状态诊断实体接入。

## 特性

- **油烟机完整控制**：开机/关机、多档位调节（爆炒/强档/弱档等）、灯光独立控制。
- **多品类只读接入**：灶具、洗碗机、净水器、蒸箱/烤箱/微波炉/消毒柜等品类以只读遥测方式接入，控制能力将在真机验证后逐品类开放。
- **延时倒计时**：支持 0–240 分钟倒计时关机（关机时自动联动保持当前档位）。
- **实时状态推送**：支持云端 SSE 实时推送与 MQTT 主动轮询，状态秒级同步。
- **双通道自动适配**：根据设备云端通信协议（REST / MQTT）自动选择最佳控制通道。
- **安全不误触**：集成加载与配置阶段仅做只读属性同步，绝不误启动抽油烟机。
- **一键诊断支持**：支持 Home Assistant 官方脱敏诊断导出，方便反馈新设备。

## 安装方式

### 方式一：HACS（推荐）

1. 打开 Home Assistant 的 **HACS** → **集成**。
2. 点击右上角菜单 → **自定义存储库 (Custom repositories)**。
3. 存储库填写：`https://github.com/darkaccount/ha-robam-roki`，类别选择 **集成 (Integration)**。
4. 在 HACS 中搜索 **ROBAM ROKI** 并点击下载安装。
5. 重启 Home Assistant。

### 方式二：手动安装

1. 下载本仓库 release 的 `robam_roki.zip` 或源码包。
2. 将 `custom_components/robam_roki` 目录复制到 Home Assistant 配置目录的 `custom_components/robam_roki` 下。
3. 重启 Home Assistant。

## 配置与使用

1. 在 Home Assistant 中进入 **设置** → **设备与服务** → **添加集成**。
2. 搜索并选择 **ROBAM ROKI**。
3. 输入老板电器 / ROKI 手机 App 的登录账号（手机号）与密码。
4. 系统会自动获取账号下的可用厨电设备，勾选需要接入的油烟机即可完成添加。

## 实体与传感器

### 油烟机（完整控制）

| 平台 (Platform) | 实体 (Entity) | 说明 |
| :--- | :--- | :--- |
| **fan** | 油烟机 | 风机开关、档位调节（百分比映射到物理档位阶梯） |
| **light** | 灯光 | 油烟机照明灯开关 |
| **number** | 倒计时 | 0–240 分钟延时关机设置（关机时不可用） |
| **sensor** | 故障代码 | 运行状态与故障自检（正常为 0） |
| **binary_sensor** | 需要清洁 | 滤油网/叶轮清洁提醒 |
| **binary_sensor** | 在线 | 机器连通性诊断 |

### 其他品类（只读遥测）

| 品类 | 实体概览 |
| :--- | :--- |
| 灶具 | 左/右灶头火力与剩余时间、工作状态、报警 |
| 洗碗机 | 工作状态与剩余时间、门开关、缺盐/缺亮碟剂提醒 |
| 净水器 | 进/出水 TDS、滤芯寿命、制水中/漏水状态 |
| 蒸箱/蒸烤一体机、烤箱、微波炉、消毒柜 | 工作状态、当前/目标温度、剩余时间、门开关与报警 |
| 其他设备 | 原始状态诊断（展示全部云端属性） |

> 以上品类目前仅提供只读遥测，不包含控制实体；控制功能将在对应品类真机验证后逐步开放。

## 支持机型与档位表

集成内置了常见老板油烟机型号的物理档位映射表：

| 型号 | 物理档位阶梯 | HA 滑块对应 | 状态 |
| :--- | :--- | :--- | :--- |
| **R8229 / R9700** | 1, 2, 3, 6 (弱/中/强/爆炒) | 25% / 50% / 75% / 100% | R8229 已实测 |
| **R66A2 / 66A2H / R8700** | 2, 6 (常规/爆炒) | 50% / 100% | 待验证 |
| **R5610** | 1, 6 (低/高) | 50% / 100% | 待验证 |
| **未列出机型** | 选项中自定义或 1..N | 线性 | 自动回退 |

> 若您的机型不在上述列表中，可以在集成的 **选项 (Options)** 中手动输入逗号分隔的档位（例如 `1,2,3,6`）。

### 申请适配新机型

如果您拥有其他型号的老板油烟机或灶具：
1. 在 Home Assistant 进入 **设置** → **设备与服务** → **ROBAM ROKI** → 点击设备进入详情。
2. 点击 **下载诊断信息**（该文件已对账号 Token、密码、设备唯一码等私密信息进行自动脱敏）。
3. 前往 GitHub [提交新设备支持 Issue](https://github.com/darkaccount/ha-robam-roki/issues/new?template=device_support.yml)，粘贴诊断信息即可。
